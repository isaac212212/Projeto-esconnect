# ESConnect — Sistema Integrado de Gestão Escolar

Plataforma Web desenvolvida para centralizar a administração acadêmica, automatizar o controle de notas e frequências e integrar a comunicação entre escola, professores, alunos e responsáveis.

---

## 📌 Visão Geral do Projeto
Nesta primeira fase (Sprint 1), a equipe realizou a concepção do produto, o diagnóstico dos problemas da gestão escolar, o levantamento de requisitos e a definição da arquitetura da aplicação.
