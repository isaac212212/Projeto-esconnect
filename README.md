# Projeto-esconnect
# ESConnect — Sistema Integrado de Gestão Escolar

Plataforma Web desenvolvida para centralizar a administração acadêmica, automatizar o controle de notas e frequências e integrar a comunicação entre escola, professores, alunos e responsáveis.

---

## 📌 Visão Geral da Sprint 1
Nesta primeira fase, a equipe realizou a concepção do produto, o diagnóstico dos gargalos da gestão escolar, o levantamento de requisitos, a definição da arquitetura web e a delimitação do escopo do MVP.
